# Open Sans

Reference: https://fda.fsu.edu/about-us

The science portal uses the Open Sans variable family with weight 300-800
and width 75%-100%. Font files are served locally by the site.

- Family CSS: https://fonts.googleapis.com/css2?family=Open+Sans:wdth,wght@75..100,300..800&display=swap
- Latin: https://fonts.gstatic.com/s/opensans/v44/mem8YaGs126MiZpBA-UFVZ0b.woff2
- Extended Latin: https://fonts.gstatic.com/s/opensans/v44/mem8YaGs126MiZpBA-UFW50bbck.woff2
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/opensans/OFL.txt

The unmodified license is included as `OpenSans-OFL.txt`. The original Hazard
site continues using its existing fonts; these assets are scoped to Science.
