# Research Notes Image Briefs

The current page uses existing project assets. The built-in image generation tool was not available in this environment, so these briefs are written for GPT image generation. Keep the generated images clean, publication-grade, and low on text.

## General Style

- Visual tone: modern academic lab website, calm but high signal.
- Palette: off-white background, charcoal text, restrained wildfire red, forest green, clear data blue.
- Texture: map rasters, gridded weather fields, satellite thermal detections, clean data panels.
- Avoid: disaster sensationalism, flames as decoration, scary smoke photos, cluttered equations, tiny labels, fake agency logos, watermarks.
- Suggested sizes:
  - Hero images: `1536x1024`
  - Paper thumbnails: `1024x1024`
  - Social preview: `1200x630`
